# Agentic Trading

Independent platform for training, evaluating and (only after explicit authorisation) operating AI trading agents.

**State:** Sprint 0 foundation scaffold. **No trading, broker connectivity, market-data feed, automatic training, CEO login or deployable live execution is implemented.** All execution capabilities are disabled.

## Sprint 0 scope
- FastAPI local read-only development skeleton
- Versioned API and trading-contract architecture
- CEO governance policies defined, not operationalised
- Local research tests and product specification
- Independent repository with no Scalp City imports or data

## Safety
Paper/live trading are disabled. Research qualification never grants live permissions. Do not deploy the unauthenticated development API publicly. Never commit credentials, financial account data, personal records or trading datasets.

## Local scaffold
The complete Sprint 0 starter package and its 14 local verification tests are available in the project handoff. This repository is being populated from that foundation.

## Roadmap
S1: authentication, CEO overview, persistent student creation.
S2: verified market data.
S3: deterministic historical replay.
S4–S8: agents, skills, memory, training, independent Academy.
S9–S11: student evolution, comprehensive controls and forward paper trading.
